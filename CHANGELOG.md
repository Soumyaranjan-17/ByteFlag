# Changelog

## [1.0.0] - 2024-11-28

### Added
- Initial release of `byteflags`.
- `ByteFlags` class for managing boolean flags in a single byte.
- Support for up to 8 flags.
- Methods: `enable`, `disable`, `toggle`, `isEnabled`, `setByte`, `getByte`.
- Serialization: `toJSON`, `fromJSON`, `toBinaryString`, `toHex`.
- Full TypeScript support.
- Unit tests with Vitest.
